# Before Asking a Senior

If you're stuck, follow these steps:

## Step 1
Read the error carefully.

## Step 2
Read the code around the error.

## Step 3
Search Google.

## Step 4
Ask ChatGPT.

## Step 5
If still stuck:

Tell us

- What were you building?
- What happened?
- What did you expect?
- Screenshot
- Error
- What did you already try?

Never ask:

"It isn't working."

Always ask:

"I tried X and Y. This happened. I think the problem is Z."
